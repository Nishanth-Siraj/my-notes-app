Create

1

S3 landing page

Starting point. The account has no general purpose buckets yet.

What you see

  • General purpose buckets tab with count (0).
  • Account snapshot and External access summary panels on the right.
  • Orange Create bucket button starts the flow.

CLI equivalent

python s3_manager.py list
2

Create bucket form

Name the bucket and review the default security settings before creating it.

Settings chosen

  • Region: ap-south-1 (Mumbai).
  • Bucket type: General purpose, global namespace.
  • Name: aws-s3-buckets-oct-2-2026-bucket.
  • Object ownership: ACLs disabled (bucket owner enforced).
  • Block all public access: enabled recommended
  • Versioning: disabled.
  • Encryption: SSE-S3 with Bucket Key enabled.

CLI equivalent

python s3_manager.py --region ap-south-1 \
  create aws-s3-buckets-oct-2-2026-bucket
3

Bucket created

Green banner confirms success and the console opens the empty bucket's Objects tab.

What you see

  • Tabs for Objects, Metadata, Properties, Permissions, Metrics, Management, File systems and Access Points.
  • Objects (0): the bucket is empty.
  • Upload and Create folder actions available.

CLI equivalent

python s3_manager.py detail aws-s3-buckets-oct-2-2026-bucket

Back on the Buckets page the new bucket appears with its region and creation timestamp.

Columns

  • Name: aws-s3-buckets-oct-2-2026-bucket

Upload files and folders

A single PNG is staged for upload to the bucket root.

What you see

  • Drag-and-drop area, plus Add files and Add folder.
  • Staged file: Screenshot From 2026-07-25 12-52-45.png, image/png, 76.6 KB.
  • Collapsible Permissions and Properties sections (storage class, encryption, tags).
  • Files over 160 GB must go through the CLI, SDK or REST API.

CLI equivalent

python s3_manager.py upload aws-s3-buckets-oct-2-2026-bucket \
  "Screenshot From 2026-07-25 12-52-45.png"

Note

  • Uploading makes the bucket non-empty, which is why the delete in step 7 is blocked.

Delete

6

Select bucket to delete

Selecting the bucket row enables the Copy ARN, Empty and Delete buttons.

What you see

  • Radio button on the bucket row is checked (1/1 selected).
  • Empty and Delete become active.

CLI equivalent

# Confirm what the bucket holds before acting on it
python s3_manager.py detail aws-s3-buckets-oct-2-2026-bucket

# Console "Empty" button  ->  empty
# Console "Delete" button ->  delete
7

Delete blocked: bucket not empty error

S3 refuses to delete a bucket that still contains objects.

What you see

  • Red alert: This bucket is not empty. Buckets must be empty before they can be deleted.
  • Confirmation input and Delete bucket button are disabled.
  • Empty bucket shortcut leads to step 8.

CLI equivalent

python s3_manager.py delete aws-s3-buckets-oct-2-2026-bucket
# AWS error (BucketNotEmpty): The bucket you tried to
# delete is not empty
  • Same rule as the console: the bucket must be emptied first (step 8), or pass --force to do both in one go.
8

Empty bucket

Type permanently delete to remove every object in the bucket.

Warnings shown

  • Emptying cannot be undone.
  • Objects added during the operation may also be deleted.
  • For large buckets, a lifecycle rule is a more efficient way to purge objects.

CLI equivalent

# Console "Empty": remove every object and version, keep the bucket
python s3_manager.py empty aws-s3-buckets-oct-2-2026-bucket
# prompts: Permanently delete ALL objects in bucket '...'? [y/N]

# Or empty and delete in one step
python s3_manager.py delete aws-s3-buckets-oct-2-2026-bucket --force
9

Delete bucket confirmation

With the bucket empty, type the bucket name to confirm deletion.

Warnings shown

  • Deleting a bucket cannot be undone.
  • Bucket names are globally unique; another account can reuse the name afterwards.
  • Access points and Multi-Region Access Points referencing this bucket will fail.

CLI equivalent

python s3_manager.py delete aws-s3-buckets-oct-2-2026-bucket
# prompts: Delete bucket '...'? [y/N]
10

Bucket deleted

Green banner confirms deletion and the bucket list is empty again.

What you see

  • Banner: Successfully deleted bucket "aws-s3-buckets-oct-2-2026-bucket".
  • General purpose buckets (0): back to the starting state.

CLI equivalent

python s3_manager.py list
# No buckets found.
